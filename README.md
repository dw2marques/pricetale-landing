# Pricetale-landing

**Pricetale** is a mobile application designed for the Portuguese literary market. It empowers book lovers to make informed purchasing decisions by instantly comparing prices across major retailers using a simple ISBN barcode scan.

## 🚀 Overview

In a market with fluctuating book prices and multiple retailers, finding the best deal can be time-consuming. Pricetale simplifies this by bridge the gap between physical discovery and digital purchase.

### Key Features

- **ISBN Barcode Scanner:** High-speed scanning to identify books instantly.
- **Real-time Price Comparison:** Live data from major Portuguese retailers (Worten, Bertrand, FNAC, and more).
- **Price Tracking & History:** Visualize price trends to buy at the right moment.
- **Availability Alerts:** Get notified when a book is back in stock or hits your target price.
- **Direct Purchase Integration:** Seamless redirection to official retailer stores for secure checkout.

## 🛠 Tech Stack (Project)

- **Mobile App:** [Flutter]
- **Backend/API:** [Node.js]
- **Data Integration:** Official Affiliate Feeds (Awin Network).
- **Landing Page:** HTML5, Tailwind CSS, hosted via GitHub Pages.

## 📈 Business Model & Compliance

Pricetale operates as a **Technology Publisher** within the affiliate marketing ecosystem. 
- **User Privacy:** The app performs searches using the end-user's device connectivity to ensure geographic relevance and adhere to anti-bot transparency.
- **Conversion Focused:** Our UI is optimized to drive high-intent users directly to the retailer's cart, reducing friction in the customer journey.
